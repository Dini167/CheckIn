## 🎯 למה נוצרה המערכת

בעסקים קטנים ובינוניים, דיווח השעות נעשה הרבה פעמים בטבלת אקסל, בכרטיס נייר או בהודעת וואטסאפ למנהל. כשחלק מהעובדים עובדים מהבית, המצב מסתבך עוד יותר: קשה לדעת מי עובד עכשיו, שעות נשכחות, תיקונים נעשים בלי בקרה, ובסוף החודש מישהו צריך לשבת ולחשב שכר ידנית.

**CheckIn מרכזת את כל זה במקום אחד:** העובד מדווח בלחיצה, ראש הצוות רואה תמונה מלאה בזמן אמת ומאשר חריגים, והשכר מחושב לבד מתוך השעות.

## 👥 למי המערכת מיועדת

| למי | מה הוא מקבל |
|---|---|
| **בעלי עסקים קטנים ובינוניים** | שליטה על שעות העבודה ועל עלות השכר, בלי תוכנה יקרה ובלי ציוד מיוחד |
| **ראשי צוותים** | מקום אחד לראות מי עובד, מי חסר, ולאשר תיקונים ואישורי מחלה |
| **עובדים — במשרד ומהבית** | דיווח פשוט מכל מחשב או טלפון, ושקיפות מלאה על השעות והשכר שלהם |

המערכת מתאימה במיוחד לצוותים בעבודה **היברידית**, שבהם חלק מהימים עובדים מהמשרד וחלק מהבית.

## 💼 איך זה מועיל לבעלי עסקים

| בעיה בעסק | הפתרון ב־CheckIn |
|---|---|
| לא יודעים מי עובד עכשיו, במיוחד מהבית | מסך **"מי במשמרת"** מתעדכן אוטומטית ומראה מי נכנס, מאיפה ומתי |
| עובדים שוכחים לדווח, ומגלים רק בסוף החודש | ימים עם **חסר בדיווח מסומנים באדום** — גם לעובד וגם לראש הצוות |
| תיקוני שעות "בדיעבד" בלי בקרה | **מכסת תיקונים שבועית** — מעבר לה, התיקון הופך לבקשה שראש הצוות צריך לאשר. אי אפשר לשלוח שתי בקשות לאותו יום |
| היעדרות בגלל מחלה בלי מסמך | העובד **מעלה אישור רפואי** עם הסבר, וראש הצוות **צופה במסמך ומאשר** |
| חישוב שכר ידני, טעויות ומחלוקות | **שכר מחושב אוטומטית** מהשעות, כולל שעות נוספות ב־125% ובונוס לראש הצוות |
| שינוי שכר באמצע חודש יוצר בלבול | **שינוי שכר נכנס לתוקף מתחילת החודש הבא**, וראש הצוות רואה מראש את השכר העתידי ומאיזה חודש הוא חל |
| עובד מאחר ולא ברור למה | **הערה לדיווח חריג** בכל כניסה, שמופיעה לראש הצוות בדוח |

**בשורה התחתונה:** פחות זמן על ניהול שעות, פחות טעויות בתלוש, ושקיפות מלאה בין העובד למנהל.

## 🧭 מה כל משתמש יכול לעשות

### עובד
- **דף הבית** — כניסה מהמשרד או מהבית (עם הערה לדיווח חריג), הפסקה, וסיום יום עם סיכום יומי. שעון חי ורשימת זמני העבודה של היום
- **הנוכחות שלי** — טבלה חודשית עם ניווט בין חודשים, סה"כ שעות וימים חסרים (מסומנים באדום)
  - **תיקון שעות** ליום חסר או ליום בלי יציאה. שני תיקונים בשבוע נכנסים מיד, ומעבר לזה התיקון נשלח לאישור ראש הצוות
  - **אישור מחלה** ליום חסר — כתיבת סיבת ההיעדרות והעלאת מסמך מהרופא (PDF או תמונה)
  - **הבקשות שלי** — כל בקשות התיקון של החודש והמצב שלהן: ממתין, מאושר או נדחה
- **השכר שלי** — שעות רגילות, שעות נוספות וסכום לתשלום

### ראש צוות — כל מה שעובד יכול, ובנוסף:
- **ניהול עובדים** — רשימת עובדי הצוות, קוד הצטרפות לעובדים חדשים, עדכון שכר שעתי ותצוגת שכר עתידי
- **מי במשמרת** — מצב הצוות כרגע, עם רענון אוטומטי
- **דוח נוכחות** — חיפוש לפי שם, סינון לפי תאריכים ומיקום, מיון, והערות העובדים לכל כניסה
- **בקשות לתיקון שעות** — הבקשות של עובדים שעברו את המכסה, עם אישור או דחייה
- **אישורי מחלה** — צפייה במסמך ובהסבר של העובד, עם אישור או דחייה. יום מחלה שאושר מסומן "חולה" ולא נחשב חיסור

## 🛠️ טכנולוגיות

**שרת:** Node.js · Express · TypeScript · Prisma · PostgreSQL · JWT · Zod · Swagger

## 💻 הרצה מקומית

**השרת** (מתוך התיקייה של [CheckIn-server](https://github.com/Dini167/CheckIn-server)):
1. `npm install`
2. `npm run db:local` — מסד נתונים מקומי (להשאיר פתוח)
3. `npm run dev` — השרת, בפורט 3000

**הלקוח** (מתוך התיקייה הזו):
1. `npm install`
2. ליצור קובץ `.env` עם השורה `VITE_API_URL=http://localhost:3000`
3. `npm run dev` — האתר, בכתובת http://localhost:5180
